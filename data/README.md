## 1. 데이터셋 레이어 개요 및 캐싱 철학

야간 소아 응급 부모에게 가장 치명적인 것은 **"지도 지오코딩 API 지연(2~8초)"**과 **"공공데이터포털 서버 장애(503/500)"**입니다.  
병원과 약국의 위치 좌표나 지정 현황은 실시간으로 변하지 않는 **준정적 데이터(Semi-static Data)**이므로, MoonlightCare는 이를 로컬 디스크 파일과 인메모리에 사전 적재하여 **조회 시 0ms 응답**을 실현합니다:

$$\text{지오코딩 API 온디맨드 호출 시: } 7,988\text{ms} \quad \xrightarrow{\text{로컬 캐시 적용 후}} \quad 261\text{ms} \quad \text{(30배 가속)}$$

## 2. 보관 데이터셋 상세 명세

### 2.1 전국 156개 달빛어린이병원 공공 API 최신 마스터 (`national_moonlight_hospitals_156.json`)
* **파일 크기**: ~ 107 KB
* **데이터 규모**: 전국 17개 시·도 156개 공식 지정 달빛어린이병원 전수 실데이터
* **도출 배경**: 공공데이터포털 국립중앙의료원(NMC) 전국 병의원 정보 API 실시간 조회 및 정제.

### 2.2 전국 2,028개 야간·심야약국 공공 API 최신 마스터 (`national_night_pharmacies_2028.json`)
* **파일 크기**: ~ 1.4 MB
* **데이터 규모**: 전국 2,028개 야간·심야 및 휴일 운영 약국 전수 실데이터
* **도출 배경**: 공공데이터포털 전국 약국 정보 API 기반 22시 이후 운영 약국 및 지자체 지정 공공심야약국 전수 정제.

### 2.3 전국 달빛어린이병원-심야약국 최신 페어링 마스터 (`nationwide_pairings.json`)
* **파일 크기**: ~ 252 KB
* **데이터 규모**: 전국 156개 달빛어린이병원 및 1:1 매칭 야간안심약국 페어링 데이터
* **도출 배경**:
  - 전국 156개 달빛병원과 2,028개 야간약국을 하버사인 구면거리로 매칭하여 최근접 조제 인프라 확립.

### 2.2 서울 530개 응급실 위경도 사전 지오코딩 캐시 (`seoul_emergency_coords.json`)
* **파일 크기**: ~ 37 KB
* **데이터 규모**: 서울특별시 관내 530개 응급의료기관 고유 코드(`hpid`) ➔ `(위도, 경도)` 매핑
* **도출 배경**:
  - E-Gen 실시간 병상 정보 조회 API(`getEmrrmRltmUsefulSckbdInfoInqire`)는 응급실 실시간 병상 수만 반환하고, 기관의 위경도 좌표(`wgs84Lat`, `wgs84Lon`)를 누락하여 반환하는 경우가 많습니다.
  - 기관 기본정보 API(`getEgytBassInfoInqire`)를 매번 호출하면 네트워크 병목이 심각하므로, 530개 기관의 위경도를 로컬 JSON에 사전 적재하여 **O(1) 해시 조회**를 제공합니다.
* **주요 JSON 매핑 예시**:
  ```json
  {
    "A1100010": [37.5796, 127.0002],  // 서울대학교병원
    "A1100013": [37.5266, 127.1086],  // 서울아산병원
    "A1100014": [37.4882, 127.0856]   // 삼성서울병원
  }
  ```

### 2.3 2021 KTAS 소아 응급환자 분류도구 임상 데이터셋 (`ktas_pediatric_dataset.json`)
* **파일 크기**: ~ 388 KB
* **데이터 규모**: 소아(신생아~만 15세 미만) 전용 168개 주증상, 17개 계통 대분류, 1차/2차 고려사항, 연령별 활력징후 기준표
* **도출 원천**:
  - `2021_KTAS_guideline_ver1.6.pptx` (대한응급의학회 / 국립중앙의료원 중앙응급의료센터) 슬라이드 192~398번
  - `2021년 KTAS 분류도구 PPT 사용방법.pdf`
  - 보건복지부 고시 「한국 응급환자 중증도 분류기준」
* **주요 구성 요소**:
  1. **소아 168개 주증상 명세**: 공식 NACRS 3자리 코드, 17대 계통 분류, 증상별 2차 고려사항(KTAS 1~5단계 조건), 활력징후 1차 고려사항, 임상 정의 노트.
  2. **MoonlightCare 7대 소아 Red Flag 연계 매핑**: 신생아 발열, 소아 경련, 청색증, 무반응, 탈수, 두부외상, 담즙성 구토와 KTAS 1~2단계 1:1 매핑.
  3. **소아 1차 임상 고려사항**: 소아 의식수준 GCS/AVPU (Slide 195), 혈역학적 상태/순환 (Slide 196), 호흡곤란/SpO2 (Slide 197), 발열 판정 기준 (Slide 198), 고위험 외상기전 (Slide 201).
  4. **연령별 정상치 기준표**: 소아 연령별 호흡수(0개월~18세, Slide 390), 소아 심박수(Slide 391), 체표면적 화상 비율(Slide 392).

## 3. 데이터 갱신 및 동기화 주기 (24시간 주기 배치)

* **관리 워커**: [`app/services/scheduler.py`](file:///e:/monnlight/app/services/scheduler.py) 내 `sync_static_datasets()`
* **실행 주기**: **매일 새벽 04:00 AM KST (24시간 주기)**
* **동작 흐름**:
  1. 이용자가 가장 적은 새벽 4시에 백그라운드 워커 기동.
  2. 공공데이터포털 NMC API를 증분 호출하여 병원 폐업/이전 및 신규 달빛어린이병원 지정 내역 수집.
  3. 로컬 JSON 파일 및 Cloud Firestore 정적 컬렉션 동시 갱신.
  4. 주간 및 야간 서비스 운영 중에는 외부 API 호출 0회 유지.
