# 🌙 지역별 야간·휴일 병원-약국 연계 및 시각화 데이터 기획안

> **문서 상태**: Approved (v1.0)  
> **작성 목적**: 야간(20시 이후) 및 주말·공휴일에 진료하는 병의원과 해당 시간대 처방전 조제가 가능한 인근 약국을 지리적·시간적으로 연계(Pairing)하고, 이용자 필수정보 및 운영시간을 직관적으로 시각화하기 위한 공공데이터 목록 및 시스템 구축 기획

---

## 1. 기획 배경 및 핵심 문제 의식

### 🚨 "야간 조제 절벽" 문제 (The Prescription Cliff)
* **현상**: 심야·공휴일에 어렵게 진료 중인 소아과나 병원을 찾아 진료를 마쳤으나, 병원 밖으로 나왔을 때 **주변 약국이 모두 문을 닫아 처방약을 조제받지 못하는 사태**가 빈번하게 발생합니다.
* **원인**:
  1. 병원 진료 마감시간(예: 21:00)과 주변 약국 영업시간(예: 20:30 마감)의 **시간적 불일치**.
  2. 공공 포털에서 병원과 약국 데이터가 완전히 분리되어 있어, 이용자가 병원 따로 약국 따로 교차 검색해야 하는 높은 탐색 비용.
* **목표**: 
  - 특정 지역(시/군/구)에서 **"지금 또는 특정 요일 야간에 진료받고 바로 약까지 탈 수 있는 [병원 ⇄ 약국] 세트"**를 한눈에 식별.
  - 상호명, 주소, 전화번호, 요일별 24시간 운영시간표, 도보/차량 이동거리, 인터랙티브 지도를 통합 시각화.

## 2. 필수 공공데이터 세부 목록 및 명세

병원과 약국의 필수 정보(위치, 연락처, 요일별 운영시간)를 확보하기 위해 다음 **4개 핵심 공공데이터 API/데이터셋**이 필요합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                      필수 공공데이터 소스 구성                         │
├────────────────────────────────┬───────────────────────────────────────┤
│ 1. 국립중앙의료원 (E-Gen)       │ 전국 병·의원 찾기 서비스 (진료시간/위치)  │
│ 2. 국립중앙의료원 (E-Gen)       │ 전국 약국 정보 조회 서비스 (운영시간/위치)  │
│ 3. 보건복지부 공공데이터셋      │ 달빛어린이병원 및 지정 협약약국 매칭 현황  │
│ 4. 한국천문연구원 (KASI)        │ 특일 정보 조회 API (공휴일/대체공휴일 판정)│
└────────────────────────────────┴───────────────────────────────────────┘
```

### [데이터 1] 국립중앙의료원(NMC) 전국 병·의원 찾기 서비스
* **제공 기관**: 국립중앙의료원 (공공데이터포털)
* **엔드포인트**: `http://apis.data.go.kr/B552657/HsptlAsembySearchService/getHsptlBassInfoInqire`
* **역할**: 전국 병·의원의 기본 인적사항, 지리 좌표, 8개 요일별 실제 진료 시작·종료시간 제공
* **핵심 추출 필드**:
  | 필드명 | 한글 설명 | 활용 목적 |
  | :--- | :--- | :--- |
  | `hpid` | 기관 고유 식별코드 | 고유 Key (중복 제거 및 관계 매핑) |
  | `dutyName` | 병·의원 상호명 | 시각화 팝업 및 타이틀 표시 |
  | `dutyAddr` | 도로명/지번 주소 | 상세 주소 안내 및 지오코딩 검증 |
  | `dutyTel1` | 대표 대표전화 | 환자 유선 문의 및 확인용 필수 링크 |
  | `dutyTel3` | 응급실 전화번호 | 응급/야간 안내 데스크 연결 |
  | `wgs84Lat` | 위도 (Latitude) | 지도 마커 렌더링 및 공간 거리 계산 |
  | `wgs84Lon` | 경도 (Longitude) | 지도 마커 렌더링 및 공간 거리 계산 |
  | `dgidIdName`| 진료과목 목록 | 소아청소년과, 내과, 이비인후과 등 필터링 |
  | `dutyTime1s ~ 8c` | **요일별 진료 시작/종료시간** | **야간(20시 이후)/휴일 운영 여부 판정의 핵심 원천** |

> **💡 요일별 시간 코드 규칙**:
> - `dutyTime1s/c` (월), `2s/c` (화), `3s/c` (수), `4s/c` (목), `5s/c` (금), `6s/c` (토), `7s/c` (일), `8s/c` (공휴일)
> - 표기 예: `0900` (09:00 오픈), `2100` (21:00 마감)

  - 소아 전문 조제약(건조시럽, 소아용 항생제 등) 재고 보유 가능성이 가장 높음.

## 3. 병원-약국 지리·시간 연계 알고리즘 (Pairing Logic)

```
[사용자 위치 / 선택 병원] 
         │
         ▼
[1단계: 지리적 공간 필터링] 
   └── 반경 500m 이내 (도보 7분, 최우선)
   └── 반경 1.5km 이내 (차량 5분, 보조)
         │
         ▼
[2단계: 운영시간 동기화 마진 검증]
   └── 약국 마감시간 >= 병원 진료 마감시간 + 30분 (처방전 조제 안전 버퍼)
         │
         ▼
[3단계: 최종 매칭 등급 부여]
   ├── 🟢 [완벽 매칭]: 공식 협약 약국 OR 30분 이상 여유 영업
   ├── 🟡 [주의 매칭]: 약국이 영업 중이나 병원 마감 후 15분 이내 마감
   └── 🔴 [조제 불가]: 반경 내 영업 약국 전무 (원내 조제 가능 여부 확인 필요)
```

1. **거리 계산 (Haversine Formula / PostGIS)**:
   - 병원 좌표 $(Lat_H, Lon_H)$와 약국 좌표 $(Lat_P, Lon_P)$ 간의 실제 지표면 직선거리 및 예상 이동시간 산출.
2. **시간 버퍼 ($T_{\text{buffer}} = 30\text{분}$)**:
   - 소아 환자 진료 후 수납 및 약국 이동, 대기 시간을 고려하여 병원 진료 마감 시간보다 최소 30분 이상 늦게 닫는 약국을 최적 약국으로 추천.

## 4. 시각화 대시보드 구성 방안 (Visualizations)

주피터 노트북 또는 웹 대시보드에서 구현할 **3대 핵심 시각화 모듈**:

### 모듈 1: 인터랙티브 연계 지도 (Folium / Leaflet)
* **병원 마커 (Blue/Purple Icon)**:
  - 클릭 팝업: 병원명, 진료과목, 오늘 진료시간, 대표전화 바로걸기, 도로명 주소.
* **약국 마커 (Green Icon: 영업중 / Gray Icon: 영업종료)**:
  - 클릭 팝업: 약국명, 오늘 마감시간, 전화번호, 병원과의 도보 거리(예: "도보 3분, 180m").
* **연계 연결선 (Polyline)**:
  - 병원과 최단거리 야간 약국을 점선으로 연결하여 최적 경로와 거리를 시각적으로 가이드.

### 모듈 2: 요일별 24시간 가동 현황 간트 차트 (Gantt / Timeline Chart)
* **X축**: 시간대 (09:00 ~ 24:00, 익일 02:00)
* **Y축**: 병원 및 매칭된 주변 약국 목록
* **표현**:
  - 병원 진료시간 막대(파란색)와 약국 운영시간 막대(녹색)를 나란히 배치.
  - 야간 안전 조제 가능 시간대(겹치는 구간)를 시각적으로 확인.

### 모듈 3: 지역구별 야간 의료 인프라 매칭률 히트맵 (Heatmap)
* 시/군/구별 야간 운영 병원 수 대비 야간 운영 약국의 비율을 산출하여, **"야간 병원은 많으나 약국이 부족한 조제 사각지대 지역"**을 경고 색상으로 시각화.

## 5. 데이터 스키마 설계안 (PostgreSQL / Pandas DataFrame)

### 🏥 병원 테이블 (`HospitalMaster`)
```sql
CREATE TABLE hospital_master (
    hpid VARCHAR(20) PRIMARY KEY,       -- 기관코드 (예: A1100001)
    duty_name VARCHAR(100) NOT NULL,    -- 병의원명
    duty_addr VARCHAR(255) NOT NULL,    -- 주소
    duty_tel1 VARCHAR(30),              -- 대표전화
    duty_tel3 VARCHAR(30),              -- 응급전화
    latitude DOUBLE PRECISION,          -- 위도 (wgs84Lat)
    longitude DOUBLE PRECISION,         -- 경도 (wgs84Lon)
    departments TEXT,                   -- 진료과목 목록
    is_moonlight BOOLEAN DEFAULT FALSE, -- 달빛어린이병원 여부
    time_mon_s VARCHAR(4), time_mon_c VARCHAR(4),  -- 월요일 시작/종료
    time_tue_s VARCHAR(4), time_tue_c VARCHAR(4),  -- 화요일
    time_wed_s VARCHAR(4), time_wed_c VARCHAR(4),  -- 수요일
    time_thu_s VARCHAR(4), time_thu_c VARCHAR(4),  -- 목요일
    time_fri_s VARCHAR(4), time_fri_c VARCHAR(4),  -- 금요일
    time_sat_s VARCHAR(4), time_sat_c VARCHAR(4),  -- 토요일
    time_sun_s VARCHAR(4), time_sun_c VARCHAR(4),  -- 일요일
    time_hol_s VARCHAR(4), time_hol_c VARCHAR(4)   -- 공휴일
);
```

### 💊 약국 테이블 (`PharmacyMaster`)

    time_wed_s VARCHAR(4), time_wed_c VARCHAR(4),
    time_thu_s VARCHAR(4), time_thu_c VARCHAR(4),

## 7. 기대 효과

1. **환자·보호자 의료 접근성 극대화**:
   - 야간에 병원 진료 후 헛걸음 없이 약까지 완벽하게 수령할 수 있는 실질적인 이동 동선 제공.
2. **응급실 쏠림 완화 기여**:
   - 경증 환자가 야간 1차 의원과 당번 약국을 원스톱으로 이용할 수 있어 상급종합병원 응급실 과밀화 완화.
3. **지자체 및 보건당국 정책 인사이트 제공**:
   - 지역별 야간 병원과 약국의 미스매칭(병원은 있으나 약국이 없는 구역)을 시각적으로 도출하여 공공 심야약국 지정 정책의 근거 데이터로 활용 가능.
